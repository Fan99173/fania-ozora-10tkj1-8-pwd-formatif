Aplikasi Catatan Harian

Proyek ini adalah aplikasi sederhana untuk mencatat kegiatan harian sederhana.

Halo! Nama saya Fania. Halaman ini berisi catatan sederhana tentang hal-hal yang saya sukai dan kerjakan sehari-hari.

Gambar di kartu ini berasal dari Minecraft, game yang sering saya mainkan di waktu luang

Dalam game Minecraft ini ternyata terdapat berbagai hal yang bisa menjadi inspirasi. Karena pemain bebas untuk berbuat dan bereksplorasi dalam game ini maka bisa menjadi pengalaman yang seru dan juga bisa membikin bangunan-bangunan indah.

Dengan berbagai bioma dan hewan yang ada di game ini, saya terinspirasi untuk menggabungkan beberapa biome dan hewan dalam satu poster.

Selain bermain game, saya suka menggambar, terutama karakter dan potret dengan gaya anime.

Menggambar membuat saya rileks setelah belajar, dan melatih saya memperhatikan warna serta tata letak.

Inspirasi gambar saya datang dari ilustrasi di internet, anime, dan benda-benda di sekitar saya.

Saya juga bermain drum, dan musik sering menemani saya saat mengerjakan tugas.

Dalam mengerjakan tugas ini, saya bisa menuangkan kreativitas desain dan juga mempertunjukkan apa yang saya sukai dalam sebuah website.

Membuat website ini telah membuat saya sadar akan beberapa kekurangan saya dalam menyusun website dan menjadi manfaat yang besar karena telah melatih kemampuan saya lebih lanjut lagi.
